### **🔧 Installation Instructions:**

1. **Install Dependencies:**
```bash
cd out_of_sync
flutter pub get
```

2. **Add Sound Files:**
Create these MP3 files in `assets/sounds/`:
- `button_tap.mp3` - Light tap sound (50ms)
- `game_start.mp3` - Game beginning fanfare (2s)
- `vote_submit.mp3` - Vote confirmation (100ms)
- `win.mp3` - Victory celebration (3s)
- `lose.mp3` - Defeat sound (2s)
- `player_join.mp3` - Player joined notification (500ms)
- `countdown.mp3` - Timer countdown beep (200ms)

3. **Run the App:**
```bash
flutter run
```
