# Flutter application

This directory contains the Out of Sync Flutter app. See the
[repository README](../README.md) for setup, project status, networking
limitations, source layout, and test instructions.

Run Flutter commands from this directory:

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d <device-id>
```

The current Dart package name is `out_of_symc`; multiplayer remains a prototype.
